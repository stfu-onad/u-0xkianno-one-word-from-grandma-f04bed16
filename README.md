# One Word From Grandma

Entry for the make.fun bounty
[u-0xkianno-one-word-from-grandma-f04bed16](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16)

`main.py` (Python 3.13, standard library only) writes exactly one word —
the word Grandma would text about AI — to `/output/entry.txt`:

> contraption

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt` — one word, 11 characters, no spaces, no
trailing newline.
